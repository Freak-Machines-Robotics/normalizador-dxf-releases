# Normalizador DXF — distribuição

Este repositório serve a distribuição do **Normalizador DXF**, a aplicação da
Freak Robotics que prepara ficheiros DXF de clientes para importação automática
no CypNest.

Aqui ficam apenas os ficheiros das versões publicadas. **O código-fonte é
privado.**

## Para quem já tem a aplicação instalada

Não é preciso fazer nada nesta página. A aplicação consulta este repositório
sozinha, descarrega a versão nova em segundo plano e avisa quando estiver pronta
a instalar — basta reiniciá-la quando a faixa do topo o pedir.

Cada lançamento traz, no corpo, o **SHA256** do pacote. A aplicação confere-o
antes de instalar seja o que for: um ficheiro que não corresponda é recusado.

## Para instalar numa máquina nova

Peça-nos o instalador. Os pacotes publicados aqui destinam-se à actualização
automática e não incluem o assistente de instalação.
